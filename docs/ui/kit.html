.scale — шкала лавинної небезпеки (Safety)

Рівень N — кроки 1..N усі несуть --active (кумулятивно), не лише крок N: «рівень 2 з 5» — це два жовтих кроки поспіль, а не один жовтий крок на позиції 2. Позиція/кількість заповнених кроків несе сенс, колір — лише підсилення; сама шкала описана `role="img"` з `aria-label`, тому не залежить від кольору. Жовтий тут — «живий стан на приладі», ніколи офіційна градація складності (green/blue/red/black лишаються за Turrutebasen).

.btn--strava · .btn--icon-lead / .i-import — Profile

Фірмові кнопки входу/імпорту (.btn--apple, .btn--google, .btn--strava) — свідома діра в закритій палітрі, як обовʼязкова атрибуція ©Kartverket. Garmin не має кодифікованої кнопки — .btn--icon-lead.i-import (стрілка вниз у лоток) це дефолтна іконка «джерело даних без власного бренду» для будь-якого майбутнього імпорту без готового брендованого стилю.

.actions--block — дії на всю ширину, одна над одною

На відміну від .actions--split (дві дії в ряд), --block ставить кожну дію на всю ширину стовпцем — коли дія одна або коли рядок для двох задовгий.
