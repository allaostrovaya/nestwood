# Скріншоти конкурентів

> Папка `research/screens/` · Кореневий індекс репо — [`../../README.md`](../../README.md)

Візуальні докази до [`../research.md`](../research.md). Збираються через Playwright під час проходження реальних флоу.

## Іменування

```
{конкурент}--{екран}--{платформа}.png
```

- `конкурент` — коротка назва в нижньому регістрі: `pitchup`, `hipcamp`, `airbnb`
- `екран` — що на скріні: `search-results`, `listing-amenities`, `checkout-step-2`
- `платформа` — `mobile` або `desktop`

Приклад: `pitchup--listing-amenities--mobile.png`

## Обовʼязково

Кожен скріншот згадується в `research.md` разом з URL і датою збору. Скрін без контексту в тексті — марний.
